# QuadPatrol · 四足智巡平台

面向配电房、变电站、工业仓储等场景的四足机器狗智能巡检平台。

QuadPatrol 将实时监控、自主导航、任务执行、异常告警和巡检报告连接成完整闭环，让机器狗真正参与日常巡检，而不只是展示一张地图。

## 平台能做什么

- **实时掌握现场**：机载画面、2D 栅格地图、3D 点云、机器人位姿与运动状态集中呈现。
- **自主完成导航**：支持单点目标、多点连续巡航、地图选点、暂停与终止任务，以及人工接管和急停。
- **闭环执行巡检**：编排巡检点和采集动作，自动执行、记录过程并生成可回溯的巡检报告。
- **及时发现异常**：集中管理告警，关联任务、巡检点和现场数据，方便定位问题。
- **统一管理设备**：接入多台实体机器狗或仿真机器狗，按设备切换地图、话题和运行模式。
- **先在仿真中验证**：在贴近真实工业环境的 GPU 场景中验证导航、控制和任务流程，降低实机调试成本。

## 一条完整的巡检流程

1. 选择机器狗和作业地图。
2. 配置巡检点、执行顺序和采集动作。
3. 启动任务，实时查看画面、轨迹与执行进度。
4. 到点自动采集并记录结果，异常时及时告警。
5. 在巡检报告中回看过程、定位问题并追溯现场。

## 快速体验

需要 Node.js 18+ 和 ROS 2 Humble 环境：

```bash
npm ci
bash scripts/start_console.sh
```

打开 [http://localhost:5173](http://localhost:5173)。

也可以单独启动室内仿真：

```bash
bash scripts/start_simulation.sh indoor
```

## 技术基础

Vue 3 · Three.js · Express · ROS 2 Humble · FAST-LIO · Nav2 · Isaac Sim
